# أفق العلوم — النموذج البصري للمراجعة

نموذج مرئي وتفاعلي فقط، وليس المنصة النهائية أو محتوى منهجياً. جميع النصوص والأمثلة عناصر توضيحية غير منسوبة إلى كتاب. صفحات الوحدة والدروس هي هياكل شكلية وليست وحدات أو دروساً فعلية. الخط والألوان غير معتمدين نهائياً.

## تشغيل محلي

يتطلب Node.js وnpm:

```sh
npm ci
npm run dev
```

يتضمن النموذج مادة موحدة للفيزياء والكيمياء، وهيكل الوحدة والدرس بمراحله السبع ودفتر الطالب، والاختبارات ومنطقة المعلم، ومقارنة الخطين ولوحة الألوان. يُعرض اختبار الوحدة كحالة غير منشأة؛ لا يُنشأ قبل تصريح صاحب المشروع بأن الدرس الأخير قُدّم. المختبر سهم هندسي بمقياس ثابت، ولا يمثل محاكاة لظاهرة علمية.

بوابتا حلول الاختبارات ومنطقة المعلم **شكليتان فقط** باستخدام كلمة المرور المطلوبة. كلمة المرور موجودة في كود العميل ولا توفر حماية أو مصادقة أمنية. لا تُنشر بيانات سرية أو حلول فعلية اعتماداً عليها؛ الحماية الفعلية تتطلب بنية خلفية ومصادقة مناسبة. لا يوجد تخزين أو حساب مستخدم أو نشر.

```sh
npm run build
```

## اختبار نسخة الإنتاج

```sh
npx playwright install chromium
npm run test:production
```

يبني الأمر الموقع ويختبره باستخدام Chromium تحت `/ChemPhys_7TH_Platform/` عبر خادم معاينة محلي، ويشمل المقاسات الأربعة والتنقل والخطوط وKaTeX والتفاعلات والبوابات الشكلية. يمكن تحديد مسار Chromium موجود عبر `CHROMIUM_PATH`. يعرض التطبيق الشاشة الرئيسية بعد تحديث الصفحة؛ التنقل في النموذج يعتمد حالة الواجهة وليس روابط مستقلة للصفحات.

## النشر بعد الموافقة

يختبر سير GitHub Actions طلبات السحب إلى `main` دون نشر. بعد الموافقة ودمج طلب السحب، يشغّل الدفع إلى `main` الاختبارات ثم يرفع `dist/` وينشرها عبر GitHub Pages إذا نجحت الخطوات وتوفرت صلاحيات وبيئة النشر. إعداد Pages الحالي هو GitHub Actions؛ لم يغيّره هذا العمل. يُراجع نجاح عمليتي Verify وDeploy في Actions ثم يُختبر الموقع الحي على `https://calesteer-create.github.io/ChemPhys_7TH_Platform/`. لا يثبت النجاح المحلي أو نجاح بناء PR حصول النشر الحي.

المخرجات داخل `dist/` وتقارير Playwright متجاهلة من Git. لا تعني هذه الفحوص اعتماد النموذج أو اكتمال اختبارات الجودة والإتاحة. إضافة المحتوى والدروس والمصادر حصرية لصاحب المشروع، ولا تُعتمد أو تُنشر دون موافقته الصريحة.
